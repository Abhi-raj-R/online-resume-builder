ATS-Friendly Resume Builder
🚀 An online resume builder that helps users create ATS-optimized resumes with modern templates.

📌 Features
✅ Create professional, ATS-friendly resumes
✅ Choose from multiple customizable templates
✅ Auto-save user input for easy resume editing
✅ Export resumes as PDF, Word, or HTML
✅ User authentication via Email & Google Sign-In

🛠 Tech Stack
Frontend: React, Tailwind CSS

Backend: Node.js, Express.js

Database: MongoDB

Authentication: Firebase / JWT
