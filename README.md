# ATS-Friendly Resume Builder

🚀 A full-stack web application that enables users to create professional, ATS-optimized resumes using modern and customizable templates. The platform simplifies resume creation by providing an intuitive interface, secure authentication, automatic data saving, and multiple export options.

## 📌 Features

* Create professional resumes optimized for Applicant Tracking Systems (ATS)
* Choose from multiple customizable resume templates
* Auto-save user information for seamless resume editing
* Export resumes in PDF, Word, and HTML formats
* Secure user authentication using Email and Google Sign-In
* Store and manage multiple resumes within a user account
* Responsive design for desktop and mobile devices

## 🛠 Tech Stack

### Frontend

* React.js
* Tailwind CSS

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### Authentication

* Firebase Authentication
* JWT (JSON Web Tokens)

## 🎯 Purpose

The ATS-Friendly Resume Builder helps job seekers create well-structured resumes that can be easily parsed by modern recruitment systems while maintaining a professional appearance. The application streamlines the resume-building process and provides flexibility through customizable templates and multiple export formats.
